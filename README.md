# WebpageAutoScrollNext
一个轻量、优雅的浏览器油猴脚本，为所有网页提供丝滑自动滚动体验，并智能识别"下一页/下一章"按钮实现自动翻页。

![version](https://img.shields.io/badge/version-1.7-blue)
![license](https://img.shields.io/badge/license-MIT-green)

## ✨ 功能特性

- **全局可用** — 适配所有网站，面板自动吸附屏幕左右边缘
- **丝滑滚动** — 基于 `requestAnimationFrame`，1~100 级速度无级调节
- **智能记忆** — 每个域名的滚动速度、跳转延迟独立保存，互不干扰
- **自动下一页** — 滚到"下一章"按钮出现时自动停止并延迟跳转，支持小说站、漫画站等
- **顶/底快捷键** — 面板附带 ↑ ↓ 按钮，一键跳转页面顶部或底部
- **空格键控制** — 全局按空格即可启停滚动（输入框内不触发）
- **回车启动** — 在速度输入框按 Enter 直接开始滚动
- **自定义选择器** — 当自动检测不准时，可为特定网站配置精确的 CSS 选择器
- **深色毛玻璃 UI** — 现代半透明面板，支持拖拽、自动隐藏、hover 高亮

## 📦 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey / Greasemonkey）
2. [点击此处安装脚本](https://update.greasyfork.org/scripts/562875/%E7%BD%91%E9%A1%B5%E7%BB%99%E6%88%91%E6%BB%9AAuto%20Scroll.user.js)

## 🎮 使用说明

| 操作 | 说明 |
|------|------|
| 点击 ▶ / ■ | 开始 / 停止滚动 |
| 按 `Space` | 全局快捷键启停（输入框内除外） |
| 输入速度按 `Enter` | 保存速度并立即开始滚动 |
| 拖拽面板 | 可吸附到屏幕左侧或右侧 |
| 点击 ↑ / ↓ | 快速跳转页面顶部 / 底部 |
| 点击 ⚙ | 打开配置面板 |
| 鼠标离开面板 | 1.2 秒后自动收缩为迷你按钮 |
